# Fitness Tracker

## Project Description
Fitness Tracker is a web-based application designed to help users track their fitness activities and maintain a healthy lifestyle.

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub
- Jenkins
- Jira

## DevOps Implementation
- **GitHub:** Source code management
- **Jenkins:** Continuous integration and automated build
- **Jira:** Project planning and task tracking

## How to Run
1. Clone or download this repository.
2. Open `index.html` in a web browser.

## Project Objective
To develop a simple fitness tracking website and demonstrate DevOps practices using GitHub, Jenkins, and Jira.
